# GMS 시세 정기 수집

일반 Chrome 확장 프로그램 → 검증된 매물 → 인증된 Worker 수신부 → D1.
수집 과정은 일반 JavaScript로 실행되며 AI API를 호출하지 않습니다.

## 실행

설치된 확장 프로그램을 새로고침하고 메소워치 페이지도 새로고침합니다.
패널에 `GMS 시세 자동 수집 v0.2.3`이 표시되어야 합니다.

- **반복 검증 3회**: 아이템 2종·최대 40곳씩 3회 조회. DB 저장 없음.
- **500건 수집·저장**: 현재 표시된 목록에서 검증 가능한 최대 500건을 한 번 수집·저장.
- **15분 자동 수집 켜기**: 첫 실행은 약 1분 뒤, 이후 15분마다 실행.
- **자동 수집 끄기**: 다음 예약만 취소. 진행 중 실행은 계속됨.
- **실행 중지**: 현재 수집과 예약을 중지. 저장 대기 결과는 보존.
- **저장 재시도**: 저장 대기 결과를 같은 실행 ID로 재전송.
- **결과 JSON 저장**: 마지막 보고서, DB 응답, 최근 실행 이력 다운로드.

확장 프로그램이 만든 별도 수집 창(`?gms-batch=1`)을 사용합니다. 창은 포커스를 가져오지 않고 열리며 사용 중인 탭을 이동시키지 않습니다.
한 번에 아이템 최대 60종·상점 최대 800곳·검증 통과 최대 500건·수집 최대 12분입니다.
다음 실행은 이전에 처리한 아이템 다음부터 시작합니다. 표시된 표본의 최신순이며 사이트 전체 최신 500건을 보장하지 않습니다.

Chrome과 별도 수집 창을 열어 두고 수집 창을 최소화하지 마세요. 숨겨진 일반 탭은 사이트 실행이 정지할 수 있어 수집 창의 활성 탭을 사용합니다.
컴퓨터가 잠들어 있는 동안은 수집하지 못하며 깨어난 뒤 알람이 재개됩니다.
아이템의 상점 목록은 최대 20초씩 두 번 기다립니다. 그래도 로딩되지 않는 아이템은 보고서의 `skippedItems`에 남기고 다음 아이템으로 넘어갑니다. 이미 수용한 매물의 검증 조건은 바뀌지 않습니다.
자동 수집이 켜진 상태에서 전체 로딩/수집 시간 초과 또는 유효 매물 없음으로 끝나면 예약을 유지하고 5·10·20·40·60분 간격(최대 60분)으로 다시 시도합니다. 그동안 15분 알람은 대기 시간을 건너뛰거나 중복 실행하지 않습니다. 저장에 성공하면 연속 실패 횟수를 초기화합니다.
수집 창 최소화·인증 화면·예상하지 못한 오류는 예약을 중지하고 확인을 요청합니다. 페이지 준비 90초 또는 실행 14분 초과는 감시 알람이 자동 복구 대기로 전환합니다. 사용자가 끄거나 중지한 예약은 자동으로 켜지지 않습니다.
실행 사이에 수집 창을 닫았다면 다음 실행에서 다시 만들고, 실행 중 닫으면 시간 초과 후 재시도합니다.
알람 상태는 서비스 워커 시작 시 복구하고 중복 실행은 저장된 실행 잠금으로 막습니다.

## 데이터 보호와 검증

- 정확한 아이템 ID/이름·개당 가격·판매자·채널·자유시장 방·원래 관측 시각을 확인합니다.
- 최근 3시간의 판매 중 매물만 수용하며 날짜가 자정을 넘어도 실제 관측 시각을 보존합니다.
- 위치 누락, 묶음/세트 가격, 수량 1이 아닌 항목, 판매 완료, 목록/상세 불일치는 제외합니다.
- 불완전하게 종료된 실행은 업로드하지 않습니다.
- 요청 전체를 검증하고 하나의 D1 트랜잭션으로 저장합니다.
- `listings`는 더 최신인 시각만 갱신합니다. 최초 관측과 이미 확인된 판매 완료 상태는 유지합니다.
- `market_observations`는 매물·관측 시각의 고유 키로 과거 기록을 보존합니다.
- 동일 실행 재전송과 같은 매물 재관측은 중복 행을 만들지 않습니다.
- 429/네트워크/5xx는 저장 대기함에서 최대 3회 시도합니다. 401/403/검증 오류는 자동 중단합니다.
- 인증 키는 `config.private.js`에만 두며 Git과 다운로드 보고서, 페이지 DOM에 포함하지 않습니다.
- 공개 페이지의 출처 표시는 변경하지 않습니다.

## 설치/서버 구성

1. `worker/migrations/0001_market_batch.sql`을 D1에 적용합니다. 기존 행은 변경하지 않습니다.
2. 수집 전용 랜덤 키를 Worker secret `MARKET_BATCH_TOKEN`에 등록합니다.
3. Worker를 배포합니다. 수신 경로는 `/internal/market-batch`입니다.
4. `extension/config.example.js`를 비공개 설치 폴더의 `config.private.js`로 복사해 같은 키를 설정합니다.
5. 기존 확장 설치 폴더에 `extension/` 파일을 반영합니다. `config.private.js`는 보존합니다.
6. Chrome 확장 관리 화면에서 사용자가 새로고침합니다. 접근 범위는 메소워치와 GMS Hub Worker 두 도메인뿐입니다.
7. 3회 검증 후 수동/예약 적재 및 중복 재전송을 확인하고 예약을 켭니다.

관리 조회: 같은 Bearer 키로 `GET /internal/market-batch` 요청 시 최근 서버 적재 20회를 조회합니다.
공개 시세 통계는 기존 Worker 예약 작업이 5분마다 재계산합니다.
실시간 시세의 가격 추이는 보존된 배치 이력과 `0002_listing_history.sql`의 공통 관측 이력을 중복 없이 사용합니다. 매물대는 현재 매물 행만 집계합니다.
