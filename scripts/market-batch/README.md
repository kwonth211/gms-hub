# GMS 시세 수집 확장

Chrome 확장 프로그램이 매물을 읽고 검증한 뒤, 인증된 Worker API에 전송합니다. 수집에는 AI API를 사용하지 않습니다.

## 설치

1. 사용할 Worker에 `MARKET_BATCH_TOKEN`을 secret으로 등록합니다. 관리 상태 조회는 별도의 `MAIL_ADMIN_TOKEN`을 사용합니다.
2. 저장소 밖에 설치 폴더를 만들고 `extension/` 파일을 복사합니다.
3. 설치 폴더의 `config.example.js`를 `config.private.js`로 복사하고 수집 키를 설정합니다. 실제 키를 저장소에 커밋하지 마세요.
4. Chrome 확장 관리 화면에서 개발자 모드를 켜고 설치 폴더를 ‘압축해제된 확장 프로그램’으로 불러옵니다.
5. 메소워치 페이지를 열고 확장 패널의 버전이 `extension/manifest.json`과 일치하는지 확인합니다.

`config.private.js`의 `name`은 수집기 구분에 사용합니다. `autoStart: true`는 브라우저 시작 시 자동 수집을 켭니다. 수동 실행부터 확인하려면 생략하거나 `false`로 설정합니다.

기존 설치를 갱신할 때는 `config.private.js`를 보존하고 확장을 새로고침하세요. 실행 중인 수집이나 저장 대기 항목을 먼저 확인합니다.

## 실행과 수집 범위

- 패널의 자동 수집 켜기·끄기로 예약을 관리합니다. 예약은 15분 주기이며, 실행 전 서버 정책과 이전 실행 시각을 확인합니다.
- 수동 수집과 재시도에도 같은 제한을 적용합니다. 실제 매물 수, 아이템 수, 상점 수, 일일 한도와 최소 간격은 서버의 사전 확인 응답으로 결정합니다.
- 서버 정책은 `worker/wrangler.toml`의 `MARKET_BATCH_*` 설정으로 관리합니다. 문서에 적힌 과거 수치를 현재 한도로 사용하지 않습니다.
- ‘반복 검증 3회’는 결과를 확인하는 기능입니다. 매물을 DB에 저장하지 않으며 상태 하트비트만 전송할 수 있습니다.
- 수집 전용 창을 재사용합니다. 일반 모드에서는 창을 최소화하지 마세요. 접근 확인 화면이 나오면 수집이 중지됩니다.

macOS에서 전용 브라우저를 사용하려면 `collector.sh`의 브라우저·프로필·로그 경로를 설치 환경에 맞추고 Chrome for Testing을 설치합니다. 기본 실행은 창이 있는 모드입니다.

```sh
./collector.sh start
./collector.sh status
./collector.sh stop
```

`run`은 프로세스를 포그라운드로 실행하고, `restart`는 재시작하며, `log`는 로그를 표시합니다. `show`와 `hide`는 launchd로 관리하는 설치의 창 모드를 전환합니다. 자동 시작 설정은 설치 환경에서 별도로 관리합니다.

## 저장과 복구

아이템 ID·이름, 가격, 판매자, 채널·방, 관측 시각을 검증합니다. 위치가 없거나 수량이 1이 아닌 매물, 판매 완료 매물, 오래되거나 불완전한 결과는 배치 저장에서 제외합니다.

- 동일 실행을 다시 보내도 중복 저장하지 않습니다.
- 오래된 관측은 최신 매물을 덮어쓰지 않습니다.
- 네트워크·429·5xx 오류는 결과를 보관하고 재시도합니다. 초기 재시도 이후에는 30분 간격으로 재시도합니다.
- 인증 오류와 검증 오류는 자동 재시도를 멈춥니다. 원인을 해결한 뒤 패널에서 재시도합니다.
- 수집이 멈추면 전용 창을 재생성하고 재시도를 예약합니다. 자동 수집을 꺼 둔 상태에서는 임의로 예약을 켜지 않습니다.

공개 `/market/status`는 수집 상태를 제공합니다. 자세한 하트비트와 적재 기록은 운영자 인증이 필요한 `/market/collector`에서 확인합니다. 서버의 실제 저장 시각을 기준으로 수집 상태를 판단하세요.

## 테스트

```sh
node --test tests/market-batch.test.mjs tests/worker.test.mjs
npm --prefix scripts/market-batch ci --ignore-scripts
npm --prefix scripts/market-batch test
```

테스트는 가상 브라우저와 메모리 DB를 사용하며 운영 서버에 매물을 전송하지 않습니다. 설치 환경의 브라우저 권한과 화면 구조는 별도로 확인하세요.
