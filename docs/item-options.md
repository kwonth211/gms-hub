# 장비 옵션 (상옵·하옵·작) 설계

다른 컴퓨터의 옵션 리더가 읽은 장비 옵션을 사이트가 받아 저장하고 보여 주는 규칙이에요.
받는 쪽은 이미 만들어져 있어요. 리더는 아래 형식대로 `opts`를 실어 보내기만 하면 돼요.

## 클래식 월드 장비 옵션은 무엇으로 이루어지나

장비 한 개의 옵션은 세 가지로 정해져요.

1. **기본값.** 게임 데이터에 아이템마다 정해진 능력치예요. 예를 들어 다크 클리브는 공격력 7이에요.
   사이트에는 이미 있어요(`data/item-details.json`의 `inc`, `slots`).
2. **드롭 때 흔들림 (상옵·하옵).** 같은 아이템이라도 떨어질 때 능력치가 기본값보다 조금 높거나 낮게 나와요.
   기본값보다 높으면 상옵, 낮으면 하옵이라고 불러요.
   흔들리는 폭의 공식은 확인된 자료가 없어서, 사이트는 공식을 쓰지 않아요. 실제 값과 기본값의 차이만 보여 줘요.
3. **주문서 작.** 주문서가 성공할 때마다 능력치가 더해지고, 성공·실패와 관계없이 업그레이드 가능 횟수가 1씩 줄어요.
   작을 한 번도 안 한 장비가 "클린"이에요.

요즘 메이플의 잠재능력·추가옵션(추옵)은 클래식 월드에 없어요.

그래서 화면에서 이렇게 읽어요.
- **클린 장비:** 기본값과의 차이가 곧 상옵·하옵이에요.
- **작한 장비:** 차이에 주문서 효과가 섞여 있어요. 사이트는 "+2"처럼 차이만 보여 주고, 상옵·하옵으로 단정하지 않아요.

## 보내는 형식

매물 한 줄(또는 확성기 한 줄)에 `opts` 하나를 더해요. 모르는 값은 빼고 보내요.

```json
{
  "stats": { "PAD": 9, "LUK": 2 },
  "slots": 5,
  "used": 2,
  "clean": false
}
```

| 필드 | 뜻 | 값 |
|---|---|---|
| `stats` | 게임 툴팁에 보이는 능력치 그대로(기본 흔들림 + 작 포함) | 정수. 0인 값은 빼요 |
| `slots` | 남은 업그레이드 가능 횟수 | 0–20 |
| `used` | 이미 쓴 업그레이드 횟수(성공+실패) | 0–20 |
| `clean` | 작을 한 번도 안 했는지 | `true` / `false` |

`stats` 이름은 게임 데이터 이름 그대로 써요. 사이트 전체(아이템 정보, 작 시뮬레이터)가 같은 이름을 써요.

| 이름 | 한국어 표시 | 영어 표시 |
|---|---|---|
| PAD | 공 (공격력) | ATT |
| MAD | 마 (마력) | M.ATT |
| STR · DEX · INT · LUK | 힘 · 덱 · 인 · 럭 | STR · DEX · INT · LUK |
| ACC · EVA | 명중 · 회피 | ACC · AVOID |
| MHP · MMP | HP · MP | HP · MP |
| PDD · MDD | 물방 · 마방 | DEF · M.DEF |
| Speed · Jump | 이속 · 점프 | SPEED · JUMP |
| CRT · CRD | 크확 · 크뎀 | CRIT · C.DMG |

## 어디로 보내나

- **상점 매물:** 지금 수집기가 쓰는 `POST /internal/market-batch`의 `rows[]` 각 줄에 `opts`를 더해요. 나머지 필드와 인증은 그대로예요.
- **확성기:** `POST /internal/megaphone`의 `rows[]` 각 줄에 `opts`를 더해요.

## 서버가 하는 일 (`worker/src/item-options.js`)

- 목록에 없는 이름, 정수가 아닌 값, 범위 밖 값은 버려요. 옵션이 이상해도 그 매물 자체는 정상으로 저장해요.
- "클린"인데 `used`가 1 이상이면 "클린"만 빼요.
- 매물 줄의 `opts` 칸(JSON 글자)에 저장해요. 같은 줄에 붙여서 데이터베이스 쓰기가 늘지 않아요.
- 같은 매물이 다음 수집 때 옵션 없이 오면 이전 옵션을 유지해요.
- 같은 판매자·채널·방·가격의 같은 아이템 두 개는 지금 구조상 한 줄로 합쳐져요. 이 경우 나중에 온 옵션이 남아요.

## 화면

- **시세 → 아이템 → 판매 매물:** 매물 줄마다 칩으로 보여요. 예) `공 9 +2` `럭 2 +2` `클린` `업횟 5/7`
  - 기본값보다 높으면 초록, 낮으면 빨강이에요.
  - 기본값에 없는 능력치(작으로 붙은 것)는 `+`로 표시해요.
- **옵션별 시세:** 옵션이 있는 매물이 두 종류 이상이면 매물 위에 "옵션별 시세" 표가 생겨요. 같은 옵션끼리 묶어서 가장 싼 값과 개수를 보여 줘요.
- **실시간 확성기:** 옵션이 온 확성기 아래에 같은 칩이 붙어요.
- 옵션이 없는 매물과 확성기는 지금과 똑같이 보여요.
